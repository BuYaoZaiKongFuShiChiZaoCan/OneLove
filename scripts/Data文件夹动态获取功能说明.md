# Data文件夹动态获取功能说明

## 功能概述

这个功能可以自动获取Data目录下的所有文件和文件夹，并以树形结构的形式在首页center区域显示。支持动态扫描，无需硬编码文件列表。

## 主要特性

### 1. 动态文件扫描
- 自动扫描Data目录下的所有文件和子目录
- 支持递归扫描多层目录结构
- 实时获取文件信息（大小、修改时间等）

### 2. 智能文件类型识别
- 自动识别文件类型并显示对应图标
- 支持多种文件格式：HTML、CSS、JS、图片、文档、音频、视频等
- 扩展性强，可轻松添加新的文件类型支持

### 3. 丰富的文件信息
- 显示文件大小（自动格式化：B、KB、MB、GB）
- 显示文件修改时间
- 鼠标悬停显示详细信息

### 4. 交互式界面
- 可折叠的文件夹树结构
- 点击文件夹展开/收起
- 点击文件直接打开或下载
- 响应式设计，支持移动端

## 技术实现

### 后端API (`/api/data/structure`)
- 使用Node.js fs模块递归扫描目录
- 返回完整的目录结构JSON数据
- 包含文件元数据（大小、修改时间、路径等）

### 前端显示
- 动态生成HTML结构
- 使用Font Awesome图标库
- CSS3动画效果
- 异步加载和错误处理

## 文件结构

```
Data/
├── biJi/                    # 笔记文件夹
│   ├── *.html              # HTML文件
│   ├── *.md                # Markdown文件
│   ├── *.jpg               # 图片文件
│   └── ...                 # 其他文件
└── Resources/              # 资源文件夹
    └── ...                 # 资源文件
```

## 使用方法

1. 确保后端服务器正在运行
2. 访问首页，在center区域可以看到"数据文件夹"部分
3. 点击文件夹名称可以展开/收起
4. 点击文件名可以打开或下载文件

## 配置说明

### 添加新的文件类型支持
在 `backend/server.js` 中的 `fileTypeIcons` 对象中添加新的文件类型：

```javascript
const fileTypeIcons = {
  '新文件类型': 'fas fa-file-icon',
  // ... 其他类型
};
```

### 修改扫描目录
在 `backend/server.js` 中修改 `dataDir` 变量：

```javascript
const dataDir = path.join(__dirname, '..', 'Data'); // 修改为你的目录
```

## 错误处理

- 如果API不可用，会自动使用静态数据作为后备
- 网络错误时会显示友好的错误信息
- 支持重试机制和超时处理

## 性能优化

- 使用异步扫描，不阻塞主线程
- 缓存目录结构，避免重复扫描
- 懒加载文件信息
- 响应式设计，适配不同屏幕尺寸

## 浏览器兼容性

- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 使用ES6+语法，需要较新的浏览器版本
- 移动端友好，支持触摸操作

## 注意事项

1. 确保Data目录存在且有读取权限
2. 大目录可能需要较长的扫描时间
3. 某些文件类型可能无法直接预览，会触发下载
4. 建议定期清理不需要的文件以保持界面整洁
